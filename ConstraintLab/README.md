# ConstraintLab

Prototype pédagogique interactif pour explorer la programmation par contraintes.

## Lancer localement

Servez le dossier `dist/` avec un serveur HTTP statique, puis ouvrez sa racine dans un navigateur. Le prototype utilise des modules ES et la persistance locale du navigateur.

## Fichiers

- `dist/index.html` : interface de l’atelier, des exemples et des notions.
- `dist/app.mjs` : interactions, visualisations et navigation dans la trace.
- `dist/solver.mjs` : modèle fini, propagation AC-3, recherche et exemples.
- `dist/style.css` : mise en page responsive.
- `dist/mark.svg` : icône du prototype.

Le dépôt contient la copie des sources du prototype hébergé sur Sites.
